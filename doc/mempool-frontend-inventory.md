# Mempool frontend inventory

The `ref/mempool` submodule is `https://github.com/mempool/mempool`, branch `master`, commit `874670fed804d092ade021d0ae74d109c7d61475`. That full SHA is `git -C ref/mempool rev-parse HEAD`. `frontend/src/app` was read. The root router is `ref/mempool/frontend/src/app/app-routing.module.ts`. The mempool backend client is `ref/mempool/frontend/src/app/services/api.service.ts`. The websocket client is `ref/mempool/frontend/src/app/services/websocket.service.ts`. Child route tables in `master-page.module.ts`, `graphs/graphs.routing.module.ts`, `lightning/lightning.routing.module.ts`, `docs/docs.routing.module.ts`, `liquid/liquid-master-page.module.ts`, and the transaction, block, tracker, and preview modules were read as well. Address and transaction screens call `services/electrs-api.service.ts`, not `api.service.ts`.

Network prefixes in `src/http_front/mod.rs` `route` (line 66) are mainnet `/api`, testnet3 `/testnet/api` (the `/testnet` arm at line 75 selects the testnet3 socket), testnet4 `/testnet4/api`, mutinynet `/mutinynet/api`, and liquid `/liquid/api`. Each of those strips `/api` before the indexer, except `/api/v1/ws`, which stays (`backend_path`, lines 112-115). `/signet` and `/signet/...` are HTTP 307 to `/mutinynet` plus the same suffix (lines 67-70). That redirect is not a backend. The Angular app has a signet tree when `SIGNET_ENABLED` is set (`app-routing.module.ts` line 97) and a regtest tree when `REGTEST_ENABLED` is set (line 143). `route` has no `/regtest` arm. The same child screens are mounted again under `/testnet`, `/testnet4`, `/signet`, and `/regtest`. Those copies are not extra rows. A liquid build (`BASE_MODULE === 'liquid'`) swaps in the liquid master page and liquid graphs. There is no `xpub` path in these route tables.

A search of `src/**/*.rs` found no MariaDB, lightning, or acceleration match. Mining pool types in the frontend carry a comment `mysql row id` (`interfaces/node-api.interface.ts` line 183). The mining screens still call HTTP. They are not classed as no backend.
