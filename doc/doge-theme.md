# Surmount DOGE

Surmount DOGE is the high-contrast theme for the splora interface.

The background is `#000000`. Body text is `#FFFFFF`. The one accent is `#FFD100`. That gold is the high-contrast DOGE accent on black. Body text stays white. There is no second accent.

This is not the Mempool wizard theme. It does not use softsimon's palette.

| Role | Hex |
| --- | --- |
| Background | `#000000` |
| Text | `#FFFFFF` |
| Accent | `#FFD100` |
